# UI Rules for Component Styling

1. Style Matching Rules:

    - Always match styles of provided design blocks or images
    - Use project color palette when available
    - Maintain consistent spacing and layout

2. Content Preservation Rules:

    - Keep original component functionality
    - Don't add features not present in original component
    - Maintain existing content and behavior

3. Element Styling Rules:

    - Apply new styles to all existing elements
    - Ensure consistent styling across similar elements
    - Maintain accessibility and usability

4. Code Quality Rules:
    - Review code for precision and accuracy
    - Ensure proper component integration
    - Maintain clean and maintainable code structure
